RSS → AI → Docs

Fetch new articles from an RSS feed, ask a specific question about each one using Claude AI, and push the answers straight into Google Docs.

☁️ One-time Google Cloud Setup — click to expand ▼
1
Go to console.cloud.google.com → create or select a project.
2
Go to APIs & Services → Library → search for Google Docs API → Enable it.
3
Go to APIs & Services → OAuth consent screen → choose External → fill in app name → add your Google account as a Test user.
4
Go to APIs & Services → Credentials → Create Credentials → OAuth 2.0 Client ID.
Choose Web application. Under Authorized JavaScript origins add the exact URL where this tool is running (e.g. http://localhost:8080 or your hosted URL — no trailing slash).
5
Copy the Client ID (ends with .apps.googleusercontent.com) and paste it in the field below.
6
Click Connect Google Docs → a Google login popup will appear → authorize → you're done. Token is stored in this browser session only.
💡 After fetching you can set a custom question per article — leave blank to use this default.
